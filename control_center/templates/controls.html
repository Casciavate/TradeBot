Kill switch

A file at state/KILL_SWITCH. While it exists, risk_gate blocks every new order. It does not depend on any process staying alive, so it keeps working even if everything else is dead or hung.

Circuit breaker

Latches when the daily-loss or drawdown limit is breached, and stays latched across restarts even if the account recovers. Only a human clears it.

{{ circuit_breaker.reason }}

{% endif %}

Equivalent commands

Everything above is also available from a terminal, which is what to use if this UI is not running: 

python scripts/kill_switch_cli.py engage "reason"
python scripts/kill_switch_cli.py disengage
python scripts/circuit_breaker_cli.py status
python scripts/circuit_breaker_cli.py reset "your name"

The kill switch is just a file, so touch state/KILL_SWITCH works too.
